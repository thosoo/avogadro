# CIF ellipsoid test data

These Crystallographic Information File (CIF) fixtures were downloaded from the
Crystallography Open Database (COD) to exercise parsing of anisotropic
displacement parameters used to draw thermal ellipsoids. Each file contains an
`_atom_site_aniso_*` loop, including `_atom_site_aniso_U_11`.

| File | Source URL | COD internal source file |
| --- | --- | --- |
| `1548467.cif` | <https://www.crystallography.net/cod/1548467.cif> | `Sci-Rep-2016-6-35685-2.cif` |
| `4335632.cif` | <https://www.crystallography.net/cod/4335632.cif> | `ic401215x_si_002_2.cif` |
| `4124388.cif` | <https://www.crystallography.net/cod/4124388.cif> | `ja5b04503_si_002.cif` |

The CIF files retain the COD headers and bibliographic metadata present in the
original downloads. Downloaded for the Open Babel test suite on 2026-07-14.
