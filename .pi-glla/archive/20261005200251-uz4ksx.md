## Completion summary

Outcome: Resolved the auditor's disapproval of change "fix-second-document-open-crash". The blocking defect was a half-implemented N.1 stale-callback guard in SurfaceExtension: `m_runningGeneration` was only ever set to 0 (ctor + setMolecule) and never captured at calculation launch, so after the first `setMolecule` bumped `m_generation` to >=1 the guard `m_runningGeneration != m_generation` was true forever and every legitimate `calculateDone()` early-returned — no surface could ever render. Fixed by adding `m_runningGeneration = m_generation` at the top of `calculate()` (mirrors OrbitalExtension::startCalculation). A second, unflagged regression was also found and fixed: the N.1/N.2 rewrite had dropped `m_molecule = molecule;` from `setMolecule`, so `m_molecule` was always null and `loadBasis()`/`calculate()` would null-deref; restored it. Added a white-box regression test `surfaceextensionTest` that drives the real `calculate()` path and asserts the captured generation equals the current one (proves the guard passes); it fails without the fix and passes with it.
