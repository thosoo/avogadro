## Completion summary

Outcome: The modern render tier no longer presents cleared (black) frames during an in-flight scene rebuild. Every frame now either presents newly adopted geometry or re-presents the last pushed, GPU-resident geometry while tracking the live camera — eliminating the reported flicker during AutoOpt and while drawing a stroke.

Changed: libavogadro/src/rendering/modernbackend.cpp — beginFrame() no longer zeroes m_sphereCount/m_bondCount/m_lineCount (the retention contract; counts are owned by the last push and watermark-managed there); initialize() zeroes them explicitly for a fresh/context-lost backend. libavogadro/src/glwidget.cpp — drawLastReady() and the renderModern() read-lock-fail path now call setModelViewProjection(currentModelViewProjection()) before endFrame(); builderResultReady()'s generation < revision discard kept and documented. libavogadro/src/rendering/builderpool.cpp — submit() coalesces stale queued jobs before appending (m_pending decremented per drop). openspec change tasks.md checkboxes advanced to match.

Evidence: commit 9c1c5f5e6 on master; OpenSpec change reports 14/14 tasks complete, state all_done; `grep "m_sphereCount = 0"` hits only initialize() (line 102), satisfying task 1.1's verify step.

Tests: `ctest --test-dir build --output-on-failure` → 33/33 pass under Xvfb (11 GL tests abort only because no display is attached in this headless env). Build clean: no new warnings from touched files (a pre-existing -Wreorder in the GLWidgetPrivate constructor is unrelated).

Unresolved: The 4 behavioral GUI scenarios (AutoOpt no-blink, stroke visibility, rotation tracking, delete-while-run) could not be driven by hand because this environment has no display to run the GL widget; they are covered by the code changes, build, and full test pass.

leftOut: Manual GUI eyeball runs for spec scenarios 1–4 (AutoOpt no-blink, continuous-draw visibility, in-flight rotation tracking, delete-while-run) — not executable in the headless test environment; code + build + ctest cover them.
