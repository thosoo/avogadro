## Completion summary

Outcome: Fixed the modern-tier non-uniform distortion (oval atoms / over-stretched bonds at all scaling, incl. 100%) at its root — GLWidget::currentModelViewProjection() composed uMVP as QMatrix4x4(proj)*QMatrix4x4(mv), which Qt's conventions turn into (modelview·projection)ᵀ. It now composes the standard projection·modelview via a new static helper.
Changed: libavogadro/src/glwidget.cpp (extracted protected static composeModelViewProjection() = proj.transposed()*mv.transposed(); currentModelViewProjection() delegates to it), libavogadro/src/glwidget.h (helper decl + ModernRenderTest friend), libavogadro/tests/modernrenderertest.cpp (2 new headless tests), libavogadro/tests/CMakeLists.txt (GLU link for the modernrenderer test), and the OpenSpec change fix-modern-tier-non-uniform-distortion (re-scoped from hidpi-render-coordinates to gpu-rendering-pipeline; new "Modern-tier projection transform correctness" requirement + 4 scenarios; all tasks updated).
